## Tool Return Contract

| Option | Description | Selected |
|--------|-------------|----------|
| Pydantic model | `FlightSearchResult` Pydantic model — most type-safe, matches ROADMAP SC#1 | ✓ |
| dict / TypedDict | Plain dict — less type-safe, same serialization burden on ChatService | |
| Keep str (JSON) | `json.dumps(structured_data)` — fragile, no type-level contract | |

**User's choice:** Pydantic model  
**Notes:** No hesitation — the Pydantic model is the natural fit.

| `to_llm_summary()` method → ToolMessage | ChatService calls summary method; LLM gets human-readable text; card gets full JSON | ✓ |
