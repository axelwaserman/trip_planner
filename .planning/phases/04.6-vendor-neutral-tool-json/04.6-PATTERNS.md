**TypeScript type-guard pattern** to add (mirrors RESEARCH.md Pattern 4):
```tsx
interface FlightSearchResultData {
  status: string
  query: { origin: string; destination: string; departure_date: string; passengers: number }
  results: FlightResultData[]
  count: number
}

function isFlightSearchResult(value: unknown): value is FlightSearchResultData {
  if (typeof value !== 'object' || value === null) return false
  const v = value as Record<string, unknown>
  return (
    typeof v.status === 'string' &&
    Array.isArray(v.results) &&
    typeof v.count === 'number'
  )
}
```

**Collapsible pattern** (lines 108–196): the expandable full result section currently renders `<ReactMarkdown>`. The new branch wraps a `JSON.parse` + `isFlightSearchResult` check before choosing the renderer:

  return (
