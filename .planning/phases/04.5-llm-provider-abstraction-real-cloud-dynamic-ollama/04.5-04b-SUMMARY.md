## Accomplishments

- Closed CONTEXT.md decisions D-15, D-16, D-17, D-18, D-28 — Plan 06's "out of orchestrator scope" gap is now reversed.
- LMStudioProvider implements LLMProvider Protocol via duck typing (no inheritance — verified by `isinstance(provider, LLMProvider)` against the @runtime_checkable Protocol).
- LMStudioProvider does NOT take an api_key constructor parameter (D-17). Settings has NO `lmstudio_api_key` field. The sentinel string `"lm-studio"` is wrapped in `SecretStr` at ChatOpenAI construction time only — never sent to api.openai.com because `base_url` overrides the destination.
- list_models hits `${base_url}/models` (base_url already includes the `/v1` prefix) and parses the OpenAI-compatible `{"object": "list", "data": [{"id": ...}]}` shape defensively. Returns `[]` on shape drift (RESEARCH.md Assumption A4) — non-list `data` field, missing `id` keys, or non-dict entries are filtered out rather than raising.
- validate_config probes for liveness + selected-model presence: `PROVIDER_UNREACHABLE` on connect/timeout/HTTPStatusError (mirrors OllamaProvider semantics), `MODEL_NOT_INSTALLED` on missing model id, `None` on success.
- Settings.lmstudio_base_url defaults to `http://localhost:1234/v1` with `LMSTUDIO_BASE_URL` env-var override (D-28 — Pydantic-settings auto-derives the env-var name from the field name).
- LLMProviderFactory.build adds `case "lmstudio":` BEFORE the default arm, wiring base_url precedence (payload > settings) per D-08 applied symmetrically to local providers. Probe timeout always reads from Settings.provider_probe_timeout_seconds (no per-session override surface in 4.5).

## Decisions Made

- **Sentinel wrapped in SecretStr.** ChatOpenAI types `api_key` as `SecretStr | Callable[..., str] | Callable[..., Awaitable[str]] | None`; passing a plain `str` fails mypy strict. Wrapping the sentinel literal `"lm-studio"` in `SecretStr(...)` resolves the type without changing runtime behavior. The literal text remains in source (in the docstring + the wrapping call) so a future grep audit for the sentinel mandate (RESEARCH.md Pitfall 3) still hits.
- **Stripped `/v1/models` literal from docstrings.** The plan's strict acceptance criterion required `grep -c '/v1/models' backend/app/llm/providers/lmstudio.py` to return `0` — the runtime URL is constructed via `base_url + "/models"`, and the literal `/v1/models` was redundant prose that risked drifting from runtime behavior. Replaced with `${base_url}/models` and explicit "the daemon's /v1 prefix is already part of base_url" wording.
- **Helper kept module-local.** `_mock_lmstudio_models_response` lives in `test_lmstudio_provider.py` rather than `conftest.py`. The Ollama analog (`mock_ollama_tags_response`) is a fixture in conftest, but its wire shape is fundamentally different (Ollama: `models[].name|model`; LM Studio: `data[].id`). Promoting the LM Studio helper to conftest would invite confusion; module-local keeps the file self-contained.
