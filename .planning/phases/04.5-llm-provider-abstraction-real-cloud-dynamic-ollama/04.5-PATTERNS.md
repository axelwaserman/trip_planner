### `backend/app/llm/protocol.py` (new — Protocol-based provider interface)

**Analog:** `backend/app/tools/flight_client.py` lines 13–82 (closest in-tree shape — abstract base class describing a provider). The Protocol is the same idea expressed via `typing.Protocol` instead of `abc.ABC` per `~/.claude/rules/python/patterns.md` (which calls out `Protocol` for duck typing).

**Imports pattern** (mirror `flight_client.py` lines 1–10 plus Protocol-specific imports from RESEARCH.md):
```python
"""LLM provider Protocol — duck-typed interface for cloud + local backends."""

from collections.abc import AsyncIterator, Sequence
from typing import Any, Protocol, runtime_checkable

from langchain_core.messages import AIMessage, AIMessageChunk, BaseMessage
from langchain_core.tools import BaseTool

from app.llm.errors import ProbeError
```

**Two-protocol shape** (RESEARCH.md §"Pattern 1" — verified against installed `langchain-core` 1.x):
```python
@runtime_checkable
class BoundProvider(Protocol):
    """A provider with tools already bound. Used by ChatService.chat_stream."""

    async def ainvoke(self, input: list[BaseMessage], **kwargs: Any) -> AIMessage: ...

    def astream(
        self, input: list[BaseMessage], **kwargs: Any
    ) -> AsyncIterator[AIMessageChunk]: ...


@runtime_checkable
class LLMProvider(Protocol):
    """Per-session provider built by LLMProviderFactory."""

    def get_provider_name(self) -> str: ...

    async def validate_config(self) -> ProbeError | None: ...

    def bind_tools(self, tools: Sequence[BaseTool]) -> BoundProvider: ...

    async def list_models(self) -> list[str]: ...
```

**Why Protocol, not ABC** (`~/.claude/rules/python/patterns.md`): Protocols enable duck typing without forcing implementers to inherit, and they survive the Phase 6 PydanticAI rework with smaller blast radius (RESEARCH.md §"Phase 6 Forward-Compat Note").

**Why two Protocols (`LLMProvider` + `BoundProvider`):** `BaseChatModel.bind_tools(...)` returns `Runnable[LanguageModelInput, AIMessage]`, NOT a `BaseChatModel`. Verified against installed `langchain-core` 1.x. A single Protocol that both has `bind_tools` AND exposes the bound surface would be a lie. See RESEARCH.md §"Pitfall 1: bind_tools Returns a Runnable, Not a BaseChatModel".

**`validate_config` — copy verbatim from `_probe_ollama` (provider_probe.py lines 57–87) with `settings.ollama_base_url` → `self._base_url`:**
```python
async def validate_config(self) -> ProbeError | None:
    try:
        available = await self.list_models()
    except (httpx.ConnectError, httpx.TimeoutException, httpx.HTTPStatusError):
        return ProbeError(
            error=ProbeErrorCode.PROVIDER_UNREACHABLE,
            message=f"Can't reach Ollama at {self._base_url}.",
            hint="Run `ollama serve` and retry, or pick another provider.",
        )
    if self._model not in available:
        return ProbeError(
            error=ProbeErrorCode.MODEL_NOT_INSTALLED,
            message=f"Ollama is running but {self._model} isn't installed.",
            hint=f"Run `ollama pull {self._model}` or pick a different model.",
        )
    return None
```

**Defensive name/model dedup** (preserve from `provider_probe.py` lines 79–80 — the existing 4.2 pattern, verified live against running Ollama 0.23.4):
```python
async def list_models(self) -> list[str]:
    url = f"{self._base_url.rstrip('/')}/api/tags"
    async with httpx.AsyncClient(timeout=self._probe_timeout) as client:
        response = await client.get(url)
        response.raise_for_status()
    payload = response.json()
    models_list = payload.get("models", [])
    # Defensive: match on `name` AND `model` per existing 4.2 pattern.
    available = {entry.get("name") for entry in models_list if entry.get("name")} | {
        entry.get("model") for entry in models_list if entry.get("model")
    }
    return sorted(available)
```

**`bind_tools` — delegates to `ChatOllama` and returns the runnable directly** (RESEARCH.md §"Pattern 1"; the `Runnable[..., AIMessage]` returned by LangChain already satisfies the `BoundProvider` Protocol structurally because it has `ainvoke` + `astream`):
```python
def bind_tools(self, tools: Sequence[BaseTool]) -> BoundProvider:
    llm = ChatOllama(
        model=self._model,
        base_url=self._base_url,
        reasoning=True,  # qwen3 thinking tokens — preserves api/main.py:41 behaviour
    )
    return llm.bind_tools(list(tools))  # type: ignore[return-value]
```

The `# type: ignore[return-value]` is required because mypy can't statically verify that `Runnable[LanguageModelInput, AIMessage]` matches the `BoundProvider` Protocol (it does at runtime via `runtime_checkable`). Add an inline comment explaining why per CLAUDE.md mypy-strict rule.

3. **`validate_config` matches `OllamaProvider.validate_config` with the corresponding "LM Studio" copy** — same try/except branches, same `ProbeErrorCode` values.

### `backend/app/llm/providers/anthropic.py` (new — cloud provider)

**Analog:** `backend/app/llm/providers/openai.py` (sibling — same shape, different SDK).

**Critical pitfall — Anthropic SDK is stricter than OpenAI** (RESEARCH.md §"Pitfall 2"): `ChatAnthropic.anthropic_api_key` is required `SecretStr` (NOT `Optional`). Constructing `ChatAnthropic(api_key=None)` raises a Pydantic validation error before any code path can probe it. Therefore `bind_tools` must run AFTER `validate_config` (which the factory ordering in `chat.py::create_session` already guarantees per Pattern 3 below).

```python
from langchain_anthropic import ChatAnthropic


class AnthropicProvider:
    def __init__(self, model: str, api_key: str | None) -> None:
        self._model = model
        self._api_key = api_key

    def get_provider_name(self) -> str:
        return "anthropic"

    async def validate_config(self) -> ProbeError | None:
        if not self._api_key:
            return ProbeError(
                error=ProbeErrorCode.MISSING_API_KEY,
                message="Anthropic needs an API key.",
                hint="Set ANTHROPIC_API_KEY on the backend, or paste a key in /settings/providers.",
            )
        return None

    def bind_tools(self, tools: Sequence[BaseTool]) -> BoundProvider:
        # ChatAnthropic requires non-None api_key at construction; validate_config gates this.
        assert self._api_key is not None  # nosec B101 — bind_tools precondition (Pitfall 2)
        llm = ChatAnthropic(model=self._model, api_key=self._api_key)
        return llm.bind_tools(list(tools))  # type: ignore[return-value]

    async def list_models(self) -> list[str]:
        return [
            "claude-3-5-sonnet-20241022",
            "claude-3-5-haiku-20241022",
            "claude-3-opus-20240229",
        ]
```

### `backend/app/llm/factory.py` (new — per-app factory)

**Analog:** `backend/app/api/main.py::lifespan` lines 30–51 (current LLM construction in `lifespan` — the factory absorbs this logic; lifespan stops constructing a default LLM).

**Shape** (RESEARCH.md §"Pattern 2"):
```python
"""LLM provider factory — builds a per-session provider from session-scoped config."""

from dataclasses import dataclass

from app.config import Settings
from app.llm.protocol import LLMProvider
from app.llm.providers.anthropic import AnthropicProvider
from app.llm.providers.lmstudio import LMStudioProvider
from app.llm.providers.ollama import OllamaProvider
from app.llm.providers.openai import OpenAIProvider


@dataclass(frozen=True)
class SessionLLMConfig:
    """Per-session LLM configuration, from request payload + Settings fallbacks."""

    provider: str
    model: str
    base_url: str | None  # local providers only
    api_key: str | None   # cloud providers only


class LLMProviderFactory:
    """Per-app factory; builds session-scoped providers."""

    def __init__(self, settings: Settings) -> None:
        self._settings = settings

    def build(self, config: SessionLLMConfig) -> LLMProvider:
        match config.provider:
            case "ollama":
                return OllamaProvider(
                    model=config.model,
                    base_url=config.base_url or self._settings.ollama_base_url,
                    probe_timeout_seconds=self._settings.provider_probe_timeout_seconds,
                )
            case "lmstudio":
                return LMStudioProvider(
                    model=config.model,
                    base_url=config.base_url or self._settings.lmstudio_base_url,
                    probe_timeout_seconds=self._settings.provider_probe_timeout_seconds,
                )
            case "openai":
                return OpenAIProvider(
                    model=config.model,
                    api_key=config.api_key or self._settings.openai_api_key,
                )
            case "anthropic":
                return AnthropicProvider(
                    model=config.model,
                    api_key=config.api_key or self._settings.anthropic_api_key,
                )
            case _:
                raise ValueError(f"Unknown provider: {config.provider}")
```

**Frozen dataclass for `SessionLLMConfig`:** matches `~/.claude/rules/python/coding-style.md` *"Prefer immutable data structures: `@dataclass(frozen=True)`"*.

**Key precedence (D-08):** `payload_key or settings.{provider}_api_key` — payload wins, env-var falls back. Identical pattern for `base_url`.

**`create_session` becomes async and absorbs the probe** (replaces existing lines 36–54 + the route-layer `await probe_provider(...)` at routes.py:128–139):
```python
async def create_session(self, config: SessionLLMConfig) -> tuple[str, ProbeError | None]:
    """Build provider, validate, bind tools, store. Returns (session_id, None) on success.

    On validation failure returns ("", ProbeError) so the route layer can map to
    a 400/502 HTTPException with structured detail (existing 4.2 wire contract).
    """
    provider = self._factory.build(config)
    if (probe_error := await provider.validate_config()) is not None:
        return "", probe_error
    bound = provider.bind_tools([search_flights])
    session_id = str(uuid.uuid4())
    self._histories[session_id] = InMemoryChatMessageHistory()
    self._bound_providers[session_id] = bound
    self._metadata[session_id] = {
        "provider": config.provider,
        "model": config.model,
        "created_at": str(time.time()),
    }
    self._last_activity[session_id] = time.time()
    return session_id, None
```

**Validators pattern — copy from `FlightQuery.validate_iata_code` (lines 39–58) and `validate_dates` (lines 60–72)**:
```python
class SessionCreateRequest(BaseModel):
    """Request model for creating a new chat session."""

    provider: str | None = Field(default=None, description="LLM provider")
    model: str | None = Field(default=None, description="Model name for the provider")
    # 4.5 NEW
    base_url: str | None = Field(default=None, description="Local providers only")
    api_key: str | None = Field(default=None, description="Cloud providers only")

    @field_validator("api_key")
    @classmethod
    def _strip_and_bound_api_key(cls, v: str | None) -> str | None:
        if v is None:
            return None
        s = v.strip()
        if not s:
            return None
        if len(s) > 256:
            raise ValueError("api_key exceeds maximum length (256 chars)")
        return s

    @field_validator("base_url")
    @classmethod
    def _validate_base_url(cls, v: str | None) -> str | None:
        # SSRF guard (RESEARCH.md §"Security Domain"): localhost only in v1.
        if v is None:
            return None
        from urllib.parse import urlparse
        parsed = urlparse(v)
        if parsed.scheme not in ("http", "https"):
            raise ValueError("base_url must be http or https")
        if parsed.hostname not in ("localhost", "127.0.0.1", "host.docker.internal"):
            raise ValueError(
                "base_url host must be localhost, 127.0.0.1, or host.docker.internal in v1"
            )
        return v
```

The `@field_validator(... mode="...")` + `@classmethod` shape exactly mirrors `FlightQuery.validate_iata_code` (lines 39–58). The `@model_validator(mode="after")` shape (lines 60–72) is also available if cross-field validation lands later.

**Source:** `backend/tests/integration/test_session_probe.py` lines 40–43; `backend/tests/unit/test_provider_probe.py` lines 24–31.
**Apply to:** All new tests that need to fake httpx calls.

```python
from unittest.mock import AsyncMock, MagicMock, patch

# Module-level mock
def _make_response(payload: dict, status: int = 200) -> MagicMock:
    response = MagicMock(spec=httpx.Response)
    response.status_code = status
    response.json.return_value = payload
    response.raise_for_status = MagicMock()
    return response

# In test: patch httpx.AsyncClient.get directly
with patch("httpx.AsyncClient.get", new=AsyncMock(return_value=_make_response({...}))):
    result = await my_async_func()
```

For tests that need integration-level (TestClient) coverage, use `monkeypatch.setattr(httpx.AsyncClient, "get", AsyncMock(...))` (test_session_probe.py:40) instead of `with patch(...)` (test_provider_probe.py:40). Both work; the unit pattern is cleaner for a single call, the monkeypatch pattern composes better with FastAPI's TestClient.
