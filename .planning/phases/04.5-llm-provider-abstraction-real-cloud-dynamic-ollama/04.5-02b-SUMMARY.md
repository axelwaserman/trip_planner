## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 3 — Blocking issue] `try/except/pass` ruff SIM105 lint**
- **Found during:** Task 3's `just check` run.
- **Issue:** `uninstall_log_scrubber` used two `try: handler.removeFilter(scrubber); except ValueError: pass` blocks; ruff SIM105 flags those as "use contextlib.suppress(ValueError)". `just check` failed.
- **Fix:** Replaced both blocks with `with contextlib.suppress(ValueError): …` and added `import contextlib` at the top of the module. Behavior identical.
- **Files modified:** `backend/app/llm/log_scrubbing.py`.
- **Commit:** `10edeaf`.

**2. [Rule 3 — Blocking issue] Import order ruff I001 lint in `__init__.py` and the test file**
- **Found during:** Task 3's `just check` run.
- **Issue:** Ruff's isort wants `SECRET_PATTERNS` (UPPER_SNAKE_CASE) before `ApiKeyScrubber` (PascalCase) inside the alphabetized import block.
- **Fix:** Reordered the import members in `backend/app/llm/__init__.py` and `backend/tests/unit/llm/test_log_scrubbing.py` to satisfy isort.
- **Files modified:** `backend/app/llm/__init__.py`, `backend/tests/unit/llm/test_log_scrubbing.py`.
- **Commit:** `10edeaf`.

### Test-Implementation Adjustments

**3. record.args dict-form test corrected to use the stdlib's documented convention**
- **Found during:** Task 2's first test run.
- **Issue:** `_make_record(msg, args={"token": "sk-…"})` raised `KeyError: 0` inside `LogRecord.__init__`. Stdlib `logging` documents that a dict-shaped `args` must be passed as the single positional element of a tuple — `args=({"token": "sk-…"},)` — and the constructor unwraps it to `record.args`.
- **Fix:** Updated `test_filter_scrubs_record_args_dict_values` to pass `({...},)` as `args`, matching the stdlib contract.
- **Files modified:** `backend/tests/unit/llm/test_log_scrubbing.py`.
- **Commit:** `0846449` (committed in same Task 2 commit; the failing run never reached `git add`).
