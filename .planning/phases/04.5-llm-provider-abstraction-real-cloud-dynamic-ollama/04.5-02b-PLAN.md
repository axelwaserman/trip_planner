From Python stdlib `logging` (module-level types):
- `class logging.Filter`: subclass and override `filter(self, record: logging.LogRecord) -> bool`. Return True to keep the record, False to drop it. We always return True (we redact, we never drop).
- `class logging.LogRecord`: has attributes `.msg` (the format string passed to the logger call) and `.args` (the % args tuple). The formatter assembles `record.getMessage()` from these AT FORMAT TIME — so mutating `.msg` and `.args` in our filter, BEFORE the handler formats, scrubs both.
- `logging.getLogger("uvicorn.access")` and `logging.getLogger("uvicorn.error")` are the loggers FastAPI/uvicorn emits request-line logs through; they have their own handlers (NOT just the root handlers) so we attach the filter to those loggers explicitly as well as to the root logger's handlers.

From `backend/app/api/main.py` (lines 17-60 — current lifespan shape):
- `lifespan(app: FastAPI)` is the asynccontextmanager that yields between startup and shutdown.
- After Plan 06 lands, the startup body builds `app.state.llm_factory` instead of constructing an LLM directly. The log-scrubber install call is inserted as the FIRST startup step (before any other code that might log).
- Shutdown today only calls `chat_service.cleanup_expired_sessions(...)` and prints a line. The uninstall call is inserted as the LAST shutdown step (best-effort) so the print line itself still gets scrubbed if it ever contains a secret.

    3. Module-level constant `SECRET_PATTERNS: tuple[tuple[re.Pattern[str], str], ...]` — a tuple of (compiled_pattern, replacement) pairs. The patterns and replacements MUST be exactly:
       - `re.compile(r"sk-ant-[A-Za-z0-9_-]{20,}")` → `"sk-ant-[REDACTED]"` (Anthropic — MUST come BEFORE the OpenAI pattern so the longer prefix wins).
       - `re.compile(r"sk-[A-Za-z0-9]{20,}")` → `"sk-[REDACTED]"` (OpenAI — runs after Anthropic so it does not cannibalize sk-ant-).
       - `re.compile(r'("[A-Za-z0-9_]*api_key"\s*:\s*)"[^"]+"')` → `r'\1"[REDACTED]"'` (JSON field name matching `api_key` or `*_api_key`; the capture group preserves the original key name and separator so `"openai_api_key"` stays `"openai_api_key"` while only the value is replaced).

       Order matters: Anthropic regex MUST be ordered before OpenAI regex (sk-ant- is a strict prefix of sk-). The JSON regex is independent and can come last.

       Bind the tuple at module load time so each LogRecord scrub is O(patterns) regex applications, not O(patterns) re.compile calls.

    4. Helper function `_scrub(text: str) -> str`: apply each (pattern, replacement) pair in order via `pattern.sub(replacement, text)`. Pure function. No mutation of input.

    5. `class ApiKeyScrubber(logging.Filter)` overriding only `filter(self, record: logging.LogRecord) -> bool`:
       - If `isinstance(record.msg, str)`: set `record.msg = _scrub(record.msg)`.
       - If `record.args` is a tuple/list: rebuild it as a NEW tuple with each str element scrubbed (and non-str elements passed through unchanged). Preserve dict-style args (when `record.args` is a single dict — rare but valid per stdlib `logging`): scrub each str value in the dict; pass through non-str values.
       - Always `return True` — never drop a record.
       - Important: do NOT call any logger inside `filter()` — that risks recursion if another scrubber is attached. Pure data transform only.

    6. `def install_log_scrubber() -> ApiKeyScrubber`: build a singleton `ApiKeyScrubber()`, attach it to every existing handler on `logging.getLogger()` (the root logger), AND attach it to `logging.getLogger("uvicorn.access")` and `logging.getLogger("uvicorn.error")` (these uvicorn loggers carry their own handlers when uvicorn is the entrypoint). Return the scrubber instance so the caller can pass it to `uninstall_log_scrubber` for cleanup. Idempotent: if the same scrubber instance is already attached to a handler, do not double-attach (check `if scrubber not in handler.filters`).

    7. `def uninstall_log_scrubber(scrubber: ApiKeyScrubber) -> None`: best-effort removal — iterate the same handlers/loggers and call `removeFilter(scrubber)` if present. Wrap each removal in try/except ValueError so partial state on shutdown does not raise.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| process memory → log handler formatter | API keys live in `ChatService._bound_providers[session_id]` (D-09). Any code path that calls `logger.info("got config %s", config)` risks emitting `repr(config)` containing the key. The scrubber sits between record creation and formatter dispatch. |
| process stdout/stderr → operator's terminal or log aggregator | Once a redacted record reaches the formatter it CAN safely be printed; the scrubber's job is to mutate the record BEFORE that boundary. |
