<objective>
Deliver LM Studio as a first-class LLM provider — closing the documented gap where the original Phase 4.5 plan-set silently dropped CONTEXT.md decisions D-15, D-16, D-17, D-18, and D-28. Plan 06 explicitly excluded `lmstudio` from the factory match dispatch ("out of orchestrator scope"); this supplemental plan reverses that omission and ships the missing class, Settings field, factory case, and unit tests.

Purpose: D-15–D-18 lock LM Studio in as a peer of Ollama. The phase goal is "real provider abstraction with dynamic local-daemon discovery" — shipping it without LM Studio leaves a CONTEXT.md decision on the floor and ships a 3-of-4 provider matrix instead of the 4-of-4 the user's locked decisions specified.

- `backend/app/llm/providers/lmstudio.py` — LMStudioProvider class wrapping `langchain_openai.ChatOpenAI(base_url=..., api_key="lm-studio")`. validate_config probes `/models` for liveness + selected-model presence. list_models reads ids from `{"object": "list", "data": [{"id": ...}]}`.

      ```
      url = f"{self._base_url.rstrip('/')}/models"
      async with httpx.AsyncClient(timeout=self._probe_timeout) as client:
          response = await client.get(url)
          response.raise_for_status()
      payload = response.json()
      data = payload.get("data", [])
      if not isinstance(data, list):
          return []
      return sorted({entry["id"] for entry in data if isinstance(entry, dict) and entry.get("id")})
      ```
