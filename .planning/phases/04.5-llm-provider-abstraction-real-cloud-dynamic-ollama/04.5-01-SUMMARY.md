## Decisions Made

- **Stay with `unittest.mock` / `monkeypatch` httpx mocking; do NOT add `respx`.** Documented in `04.5-RESEARCH.md` §"Validation Architecture" Open Question 2 — research-resolved before this plan started, just preserved here.
- **Function-level `@pytest.mark.skipif` on the cloud-acceptance tests, not module-level.** Lets a partially-credentialled CI environment (only one of `OPENAI_API_KEY` / `ANTHROPIC_API_KEY` set) still run the available test instead of skipping the whole module. The `pytest.mark.integration` marker IS module-level (`pytestmark = pytest.mark.integration`).
- **Factory-shape fixture for `mock_ollama_tags_response`** — fixture returns a callable `(model_names: list[str]) -> MagicMock` so each downstream test (Wave 2) can supply its own model list without re-importing the helper. Cleaner than re-running `pytest.fixture` per parametrization.
- **Skip-body reasons name the implementing wave** (e.g., `pytest.skip("Wave 2 implements OllamaProvider")`) so future executors can find the right plan from the test alone. The doctrings inside each test stub then carry the canonical Wave-N assertion shape.
- **`langchain` (umbrella) NOT removed in 4.5** — pre-resolved per RESEARCH.md §"Open Questions" Q1; defer to Phase 6 alongside the wholesale LangChain teardown. Avoids dependency churn risk in the same phase that adds two new packages.
