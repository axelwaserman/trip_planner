## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → POST /api/chat/session | The user (or attacker who has stolen a JWT) controls the JSON body, including the new base_url and api_key fields. |
| backend → Settings env vars | OPENAI_API_KEY / ANTHROPIC_API_KEY env vars set at process start. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04.5-02-01 | Tampering / SSRF | SessionCreateRequest.base_url | mitigate | _validate_base_url enforces scheme ∈ {http, https} AND hostname ∈ {localhost, 127.0.0.1, host.docker.internal}. Rejects metadata-service IPs, internal subnets, file:// schemes. |
| T-04.5-02-02 | Denial of Service | SessionCreateRequest.api_key (pathological length) | mitigate | _strip_and_bound_api_key caps len(stripped) ≤ 256 chars. |
| T-04.5-02-03 | Information Disclosure | api_key field name surfaced in OpenAPI schema | accept | Field description explicitly states "Stored in session memory only — never logged or persisted." Future Phase 8 structlog scrubber filters log lines; Plan 04.5 ships only the Pydantic-level posture. |
| T-04.5-02-04 | Information Disclosure | ProbeErrorCode import path change | accept | Wire-level enum values unchanged; frontend mapProbeError unaffected. Docstring in app/llm/errors.py warns future contributors against renaming wire codes. |
| T-04.5-02-05 | Tampering | Provider name injection (e.g. provider="../../etc/passwd") | mitigate | Plan 06's factory.build() uses match config.provider against a fixed Literal set; Plan 02 establishes the SessionLLMConfig dataclass that constrains the type. |
</threat_model>
