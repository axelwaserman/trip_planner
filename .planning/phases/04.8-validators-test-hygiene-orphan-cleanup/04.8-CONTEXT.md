<decisions>
## Implementation Decisions

### Validator clock anchoring

- **D-01: `FlightQuery.departure_date >= today` uses `datetime.now().date()` directly in the validator body.** No injectable clock, no `pytest-freezegun`, no `Settings.today_factory`. Tests pass a future date for valid cases and a past date for invalid cases — no time-travel needed.

- **D-02: Boundary is `>= today` (same-day bookings are valid).** Matches REQ-pydantic-validators literally.

- **D-03: The arrival-after-departure validator applies to BOTH `Flight` and `FlightSegment`.** Both models carry `departure` and `arrival` datetimes. Applying the same `@model_validator(mode="after")` to both is additive and complete. `FlightQuery` and `FlightResult` do not carry this field pair and need no change.

### parse_sse_events() helper

- **D-04: Location is `backend/tests/utils/sse.py`.** Backend test utility only — the frontend has its own `parseSSE.ts`.

- **D-05: Accepts raw SSE text (`str` or `list[str]`).** Decoupled from FastAPI's `TestClient` so it's usable in both unit and integration contexts.

- **D-06: Returns `list[StreamEvent]`.** Typed and Pydantic-validated. Phase 4.7 updates the return type annotation to the discriminated union in one line — no structural rework needed.

### create_mock_flight() factory

- **D-07: Factory covers `Flight`, `FlightQuery`, and the Phase 4.6 vendor-neutral models (`FlightSegment`, `FlightResult`).** All flight-domain model construction is centralised. Tests that only need one type still use only that function — others remain inline if simple enough.

- **D-08: All factory functions accept keyword overrides with sensible defaults.** Callers specify only the fields relevant to the assertion. Example: `create_mock_flight(origin="JFK", price=Decimal("999"))`. Defaults produce a valid model with no further required args.

- **D-09: Location is `backend/tests/fixtures/flights.py`.** Companion to the existing `backend/tests/fixtures/llm.py` (MockLLMStream from Phase 4.4).

### Orphan deletion

- **D-10: Delete `frontend/src/components/ToolCallCard.tsx` and `frontend/src/components/ToolResultCard.tsx`.** Confirmed zero imports across the entire `frontend/src/` tree. No migration needed.

</decisions>

## Specific Ideas

- Factory function names: `create_mock_flight()`, `create_mock_flight_query()`, `create_mock_flight_result()`, `create_mock_flight_segment()` — consistent prefix, one per model.
- `parse_sse_events()` should skip non-data lines (`""`, `": keepalive"`, etc.) and only parse `data: {...}` lines.
- The `departure_date >= today` test should freeze the date in a helper constant (e.g., `PAST_DATE = date(2020, 1, 1)`, `FUTURE_DATE = date(2099, 1, 1)`) rather than computing relative to `datetime.now()` — keeps tests deterministic without `freezegun`.
