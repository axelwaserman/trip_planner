<objective>
Split the existing `ConversationStore` ABC into the two locked abstractions from CONTEXT.md D-05/D-06: `MessageStore` (events) and `ConversationRepository` (meta-CRUD). Each ABC gets an `InMemory*` impl (replacing the Phase 5 in-memory store) and a `Postgres*` impl. The PostgresMessageStore round-trips PydanticAI `ModelMessage` lists through JSONB columns; the PostgresConversationRepository owns user-scoped conversation listing in SQL.

Purpose: Plan 04 rewires `ChatService` to consume both ABCs together. Without this split, the Postgres impl cannot ship cleanly because the existing `ConversationStore.list_for_user` peeks into `_store` (CR-04 from Phase 5 verification — `getattr(self._conversation_store, "_store", None)` silently returns None against a non-in-memory impl). Splitting the ABC and moving `first_user_message_preview` onto `MessageStore` closes that anti-pattern.
Output: two new ABCs in their canonical home modules, four concrete impls (two in-memory, two Postgres), shared contract tests parametrised over both impls.
</objective>

<!-- D-05 / D-06 ABC contracts (CONTEXT.md verbatim): -->
class MessageStore(ABC):
  @abstractmethod async def append(self, conversation_id: UUID, messages: list[ModelMessage]) -> None: ...
  @abstractmethod async def load(self, conversation_id: UUID) -> list[ModelMessage]: ...
  @abstractmethod async def delete(self, conversation_id: UUID) -> None: ...
  @abstractmethod async def first_user_message_preview(self, conversation_id: UUID) -> str | None: ...

class ConversationRepository(ABC):
  @abstractmethod async def create(self, *, user_id: UUID, provider: str, model: str) -> UUID: ...
  @abstractmethod async def get(self, conversation_id: UUID) -> ConversationRecord | None: ...
  @abstractmethod async def list_for_user(self, user_id: UUID) -> list[ConversationRecord]: ...
  @abstractmethod async def bump_last_activity(self, conversation_id: UUID) -> None: ...
  @abstractmethod async def delete(self, conversation_id: UUID) -> None: ...

<!-- ConversationRecord shape (planner discretion — narrow DTO returned by ConversationRepository.get/list_for_user): -->
- `id: UUID`, `user_id: UUID`, `provider: str`, `model: str`, `created_at: datetime`, `last_activity_at: datetime`, `first_message_preview: str | None` (preview is denormalized into list_for_user via a JOIN to MessageStore.first_user_message_preview; for `get` it stays None and the caller composes if needed)

<!-- PydanticAI JSONB round-trip (RESEARCH §Pattern 3): -->

- load: `ModelMessagesTypeAdapter.validate_python(list(rows))`

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| `ChatService` → `MessageStore` ABC | Conversation messages cross the seam; the ABC is the only allowed shape — no `getattr(_store)` peeks |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
