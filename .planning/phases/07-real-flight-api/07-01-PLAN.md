<!-- Public API of `retry_on_failure` that MUST be preserved. -->
From backend/app/tools/retry.py (current signature — DO NOT change):

```
def retry_on_failure(
    max_retries: int = 3,
    backoff_base: float = 2.0,
    exceptions: tuple[type[Exception], ...] = (APIError,),
) -> Callable[[Callable[P, Awaitable[R]]], Callable[P, Awaitable[R]]]:
```

Behavior contract (locked by existing tests):
- Returns a decorator that wraps async functions.
- Retries when the raised exception is an instance of `exceptions` AND has `retryable=True` attribute.
- Does NOT retry non-retryable errors (`APIClientError(retryable=False)` raises on first attempt).
- Preserves `__name__` and `__doc__` via `functools.wraps` (tenacity's `@retry` does this automatically).
- After all attempts are exhausted, raises the original exception (NOT `tenacity.RetryError`).

From backend/app/exceptions.py:
- `APIError(message: str, retryable: bool = False)` — base
- `APITimeoutError(retryable=True)`, `APIRateLimitError(retryable=True)`, `APIServerError(retryable=True)`, `APIClientError(retryable=False)`
