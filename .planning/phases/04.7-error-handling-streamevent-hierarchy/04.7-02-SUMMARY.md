## Decisions Made

- **Retry strategy**: `chat_stream(message="Please retry the previous {tool_name} call.", session_id=...)` reuses the existing tool-calling loop. No new LangChain primitives. The agent's persisted history provides context; the synthetic prompt triggers the same code path (D-09).
- **Cross-user test isolation**: user B injected directly into `_users_db` module dict with `try/finally` cleanup. Avoids `AUTH_USERS` env restart overhead while exercising the real `get_current_active_user` auth path.
- **422 constant**: used `HTTP_422_UNPROCESSABLE_CONTENT` (not deprecated `HTTP_422_UNPROCESSABLE_ENTITY`) to keep the test suite warning-clean.
- **StructuredTool patch pattern**: `patch.object(type(search_flights), 'ainvoke', new_callable=AsyncMock, ...)` patches the class-level method. Pydantic v2 model instances block `__setattr__` for non-field names, so instance-level `patch.object(search_flights, 'ainvoke', ...)` raises `AttributeError`. Class-level patch works and is reverted cleanly by the context manager.
