## ErrorEvent payload + error taxonomy

### Q1: Error codes

| Option | Description | Selected |
|--------|-------------|----------|
| Minimal: session_error / tool_error / stream_error | 3 codes as StrEnum. Simple, covers acceptance criteria. | ✓ |
| Granular: 6+ codes | provider_error / session_not_found / tool_timeout / etc. More precise but overlaps Phase 4.5 ProbeError. | |
| Single code + message string | No StrEnum — just message: str. Frontend can't route without parsing text. | |

**User's choice:** Minimal 3-code taxonomy as StrEnum.
**Notes:** Clean split. Keeps taxonomy concerns out of Phase 4.7 scope.
