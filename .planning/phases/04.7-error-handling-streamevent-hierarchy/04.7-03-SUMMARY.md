With:

- `ErrorEvent { type: 'error'; error_code: ErrorCode; message: string; retryable: boolean; tool_name?: string; raw_detail?: string; session_id: string }`

`parseSSELine` now returns `ChatStreamEvent | null` (guard logic unchanged).

## Resolved API Discovery (for Plan 04 to inherit)

**RESEARCH.md A1 was flagged as ASSUMED — now VERIFIED:**

The `Toaster` component from `@chakra-ui/react` v3.28.0 does **NOT** accept `<Toaster toaster={toaster} />` (self-closing) — it requires a `children` render function per the underlying `@ark-ui/react` Toaster contract:

```tsx
<Toaster toaster={toaster}>
  {(toast) => (
    <ToastRoot key={toast.id}>
      {toast.title && <ToastTitle>{toast.title}</ToastTitle>}
      <ToastCloseTrigger />
    </ToastRoot>
  )}
</Toaster>
```

**Plan 04 should import `Toaster`, `ToastRoot`, `ToastTitle`, `ToastCloseTrigger` from `@chakra-ui/react`** (already done in App.tsx). The `toaster` singleton is called as `toaster.create({ title, type, duration })`.
