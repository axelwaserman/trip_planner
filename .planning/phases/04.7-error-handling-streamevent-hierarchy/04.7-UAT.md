## Additional Issues Found and Fixed (UAT session)

During real LMStudio testing, 4 additional bugs were found and fixed:

1. **LMStudio empty tool args (`{}`)** — Backend `chat_stream` was using `isinstance(chunk, AIMessage)` which matches `AIMessageChunk` (a subclass), causing early tool-call processing before JSON args were assembled. Fixed by accumulating all `AIMessageChunk`s with the `+` operator and processing `tool_calls` only after the stream loop ends.

2. **Refresh models button always errors** — `useProviderRefresh.ts` treated the response as a dict but backend returns `{providers: [...]}` array. Fixed with `.find()` lookup. Also added `available: false` check so invalid base URLs surface a proper error.

3. **LMStudio models not in model picker** — `buildQuickSwitchOptions` in `ChatInterface.tsx` had no lmstudio block. Added block matching the ollama pattern.

4. **Sidebar row overlap + no reordering** — Button rows lacked `w="full"` causing overlap; refetch after stream end added via streaming count delta check.
